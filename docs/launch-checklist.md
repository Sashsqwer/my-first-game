## Что нужно от тебя 👤 — пошаговый план открытия

1. **Секрет бота.** GitHub → репозиторий **alex-bots** → Settings → Secrets and variables → Actions → секрет `GAME_BOT_TOKEN` (токен @startup_zero_bot от @BotFather). Токен в чат не присылай.
2. **Выложить сервер.** Скажи «выкладывай» для alex-bots — я запушу коммит с правками сервера, сделаю прогон на копии с MariaDB и запущу выкладку. Таблицы игры создадутся миграцией, кнопку меню «Играть» и вебхук бот поставит сам.
3. **BotFather.** `/mybots` → **startup_zero_bot** → **Bot Settings** → **Configure Mini App** → **Enable Mini App**, адрес `https://sashsqwer.github.io/my-first-game/`. Это нужно, чтобы ссылки-приглашения `t.me/startup_zero_bot?startapp=…` открывали игру сразу. Там же можно загрузить картинку `app/img/og.png` как превью.
4. **GitHub Pages** (если ещё не включён): my-first-game → Settings → Pages → Source: **GitHub Actions**.
5. **«Выкладывай» игру.** Я слью `dev` в `main` — Pages выложит игру за 1–2 минуты.
6. Проверка с телефона: открыть бота → «Играть» → пройти обучение → «Пригласить» друга → друг играет 10 минут → у тебя в «Друзьях» он засчитан.

Пополнять GenAPI для игры не нужно — нейросети в ней не используются.
