# Сотрудники от нейросети — решение владельца (25.11.2026)

Пробные листы (GPT Image 1.5 в GenAPI, высокое качество, 36 ₽ за лист 12 персонажей):
- `2-multyashnyj-OSNOVNOJ.jpg` — **основной стиль сотрудников** (яркий мультяшный, толстые контуры). Его видят все игроки.
- `1-figurki-3d.jpg` — **3D-фигурки** — комплект «Коллекция» (платный).
- `3-nochnoj-neon.jpg` — **неоновые** — комплект «Ночной неон» (платный).

Обновление (26.11.2026): стили идут комплектами «оформление + сотрудники» — основной «Сочный офис» + мультяшные, «Ночной неон» + неоновые, «Коллекция» + 3D-фигурки (README → «Стили-комплекты»).

План отрисовки (после пополнения GenAPI владельцем — он скажет):
- Листами по 12 персонажей в выбранном стиле, затем нарезка кодом на отдельные картинки `app/img/staff/<стиль>/<бизнес>-<уровень>.webp`.
- 64 персонажа (8 бизнесов × 8 уровней) ≈ 6 листов × 36 ₽ ≈ 220 ₽ на набор; три набора ≈ 650–680 ₽.
- Без логотипов (Apple и т.п.), без сигарет/алкоголя; описание каждого уровня — `app/content.js` (BIZ[...].staff), внешность как в `app/avatars.js` (детерминированно по бизнесу и уровню).
- В коде готово: `avatar(business, level, rarity, cls, kit)` берёт `app/img/staff/<main|neon|collection>/<бизнес>-<уровень>.webp`, если имя есть в списке комплекта `STAFF_IMG` (`app/content.js`), иначе — SVG; набор выбирается по надетому стилю.
