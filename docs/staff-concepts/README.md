Пробные листы (GPT Image 1.5 в GenAPI, высокое качество, 36 ₽ за лист 12 персонажей):

- 64 персонажа (8 бизнесов × 8 уровней) ≈ 6 листов × 36 ₽ ≈ 220 ₽ на стиль; два стиля ≈ 430–450 ₽.

- В коде: `avatar(business, level, rarity)` уже берёт картинку, если она есть в списке; нужно добавить выбор набора по стилю (основной → мультяшные, скины → фигурки).
