# Стартап с нуля

Telegram Mini App игра (idle + merge): выбираешь один из 8 бизнесов (☕ кофейня, 💻 IT-стартап, 💇 барбершоп, 🍔 бургерная, 🚗 автосервис, 🏋️ фитнес-клуб, 🎮 игровая студия, 🚚 доставка), нанимаешь сотрудников, объединяешь двух одинаковых в одного уровнем выше, заботишься о команде и переезжаешь в помещения побольше.

- Бот: [@startup_zero_bot](https://t.me/startup_zero_bot)
- Концепция: `docs/concept/concept-v2.pdf` (v1 — `concept-v1.pdf`) (исходник — `concept.html`), варианты — `variants.html` (выбран 05 «Империя → Холдинг»)
- Стиль: основной комплект «Сочный офис» (мультяшный, светлый) + платные «Ночной неон» и «Коллекция» — см. «Стили-комплекты» ниже, коллаж `docs/screens/final-style.png`
- Статус: **0.6, готовим открытие** — новый основной стиль и стили-комплекты; редкость, кадровое агентство, забота, календарь, задания дня, аврал ×2, 8 бизнесов, подсказки после обучения, «Похвастаться»; друзья и рейтинг — через `app/net.js` (сервер в alex-bots), без сервера — заглушки. Чек-лист и план открытия — `docs/launch-checklist.md`

## Что внутри

| Папка / файл | Что это |
|---|---|
| `app/index.html`, `app/style.css`, `app/game.js` | сама игра, без сборщиков и npm |
| `app/content.js` | тексты 8 бизнесов: сотрудники, шутки, помещения, улучшения, потребности |
| `app/theme.js`, `app/themes.css`, `app/themes-main.css`, `app/themes-neon.css`, `app/themes-collection.css` | оформление — стили-комплекты: основной «Сочный офис» (`main`, `themes-main.css`), «Ночной неон» (`neon`, `themes-neon.css`), «Коллекция» (`collection`, `themes-collection.css`); общее — `themes.css`. Надеваются в ⚙️ → «Стили»; `?theme=main\|neon\|collection` — только для проверки, ничего не сохраняет |
| `app/avatars.js` | сотрудники, нарисованные кодом (SVG): `avatar(бизнес, уровень, редкость)` |
| `app/net.js` | связь с сервером (друзья, приглашения, рейтинг) — `window.GameNet` |
| `app/balance.js` | все цифры баланса (цены, доход, помещения, улучшения) — общие для игры и симуляции |
| `tools/simulate.js` | прогон «разумного игрока» по формулам: `node tools/simulate.js 40` (минут; `--plain` — без новых механик) |
| `tools/screens.js` | проверка в браузере (Playwright, iPhone 13) + скриншоты в `docs/screens/` |
| `tools/playtest.js` | полный проход игры автотестом (iPhone 13 и 320×568, стили-комплекты и перевод старых стилей, Telegram, без сервера, сохранения, время, скорость): `node tools/playtest.js` |
| `tools/og.js` | обложка для ссылок `app/img/og.png` и иконки `app/img/icon-180/512.png` — рисуются кодом |
| `.github/workflows/pages.yml` | выкладка папки `app/` на GitHub Pages при каждом push в `main` |

Сохранение — в браузере (localStorage), а в Telegram ещё и в облаке Telegram (CloudStorage, берётся более свежее). Сбросить — ⚙️ → «Сбросить прогресс».

## Играть локально

Просто открой `app/index.html` в браузере. Или с локальным сервером:

```
python3 -m http.server -d app 8000
```

и зайди на http://localhost:8000. Удобнее смотреть в режиме телефона (F12 → значок телефона).

## Включить GitHub Pages (один раз)

1. На GitHub: репозиторий **my-first-game** → **Settings** → **Pages**.
2. **Source: GitHub Actions**.
3. Вкладка **Actions** → «Pages» → **Run workflow** (или просто любой push в `main`).
4. Через 1–2 минуты игра будет по адресу https://sashsqwer.github.io/my-first-game/

## Привязать к боту

В Telegram у **@BotFather**:

- `/mybots` → **startup_zero_bot** → **Bot Settings** → **Menu Button** → URL `https://sashsqwer.github.io/my-first-game/`, текст кнопки «Играть».
- Или `/newapp` → выбрать бота → ссылка та же — тогда игра откроется по адресу вида `t.me/startup_zero_bot/game`.

Токен бота в чат не нужен — для этого шага он вообще не нужен.

## Баланс (0.4, «медленный»)

- Доход в интерфейсе — в ₽/час (внутри считается посекундно). Сотрудник 1-го уровня — 180 ₽/ч, каждый уровень ×2,2, редкость: редкий ×1,5, эпик ×2, лега ×5. Найм: каждый следующий ×1,17.
- 8 ступеней офиса: доход ×1 → 1,4 → 1,9 → 2,6 → 3,5 → 4,8 → 6,5 → 9; рядов 3,3,4,4,4,5,5,5. Переезд: сотрудник 5,5,6,6,7,7,8 уровня и 200 тыс. / 800 тыс. / 2 / 6 / 18 / 50 / 150 млн ₽. Старые сохранения (3 помещения) переводятся: 2-е → «Свой офис», 3-е → последняя ступень.
- Переезд списывает свою цену (остальные деньги остаются).
- Тап — 10 секунд дохода сотрудника, но не меньше 1 ₽ (раз в 5 сек с каждого).
- Задания дня: «найм», «слияния», «улучшения» подстраиваются под доход (`B.questNeed`): в начале — найми 15 / объедини 12, дальше — сколько покупают 2–3 часа дохода; невыполнимые в этот день не выпадают. Награда — 30 мин дохода, сундук за все три — пачка из 2 резюме + осколок (`CHEST_PACK`).
- Темп по симуляции (4 захода в день по 10 минут, офлайн, аврал, задания и сундуки): 4-й найм ~1 мин, первое задание ~5 мин, 5-й уровень ~4 ч, 7-й ~2 дня, 8-й ~7 дней, 1-й переезд 1–2 дня, последний офис ~28 дней. Сравнить со старым: `node tools/simulate.js --balance=tools/balance-old.js`.
- Забота: 3 шкалы падают за 6/7/8 ч; при средней ниже 50% доход падает до −50%; восстановить — тап, раз в 10 мин.

## Стили-комплекты (0.6)

Стиль — это **комплект «оформление + сотрудники»** (`B.SKINS` в `app/balance.js`, выбор — ⚙️ → «Стили», у каждого комплекта превью: сцена + сотрудник):

| Комплект | id | Как открыть | Оформление | Сотрудники |
|---|---|---|---|---|
| **Основной** «Сочный офис» | `main` | бесплатно, у всех по умолчанию | тёплый офис: обои, окно с городом, часы, растения, паркет; доска — пол в рамке, клетки — коврики, пластиковые кнопки, у каждого бизнеса свой цвет | мультяшные |
| **Ночной неон** | `neon` | 3 друга **или** ⭐ 75 | бывший основной: ночь, город, туман, дождь, мокрая улица с отражением, неон и золото | неоновые |
| **Коллекция** | `collection` | ⭐ 150 | витрина коллекционера: студийный фон, мягкие софиты, полки с коробками; доска — шкаф в ореховой раме, клетки — ниши с подсветкой, сотрудник на круглой подставке, имя — латунная табличка, редкость — цвет подставки | 3D-фигурки |

- Оплата ⭐ пока «скоро» (кнопка показывает подсказку).
- Картинки сотрудников — по комплектам: `app/img/staff/<main|neon|collection>/<бизнес>-<уровень>.webp`, списки — `STAFF_IMG` в `app/content.js` (пока пустые → везде SVG из `app/avatars.js`).
- `?theme=main|neon|collection` — посмотреть стиль без сохранения; `&preview_staff=1` — в основном комплекте вместо SVG мультяшные персонажи с пробного листа (нарезка: `python3 tools/staff-preview.py` → `app/img/staff-preview/`, только для просмотра).
- **Выбор вида «Коллекции» (временно, ждёт решения владельца):** 3 варианта — 1 «Бутик игрушек» (тёмный бархат цвета бизнеса, латунь, стеклянные ниши с прожектором; сейчас выбран — `?theme=collection`), 2 «Блайнд-бокс студия» (`?theme=collection2`: яркая пастель, клетки — коробки с окошком, у редких — фольга), 3 «Капсульный автомат» (`?theme=collection3`: корпус автомата цвета бизнеса, клетки — капсулы). CSS — `app/themes-collection1|2|3.css` поверх `themes-collection.css`, в «Стили» варианты не добавлены. С 3D-фигурками: `&preview_staff=1` (нарезка листа — `python3 tools/staff-preview-3d.py` → `app/img/staff-preview-3d/`). Скриншоты и коллаж: `node tools/collection-variants.js` → `docs/screens/collection-variants/` и `docs/screens/collection-variants.png`. После выбора — оставить один файл, убрать `data-cv` из `theme.js`.
- Старые стили убраны (код — в истории git). Сохранения переводятся без потерь: надетые «Полночь»/«Ночной Токио» → «Ночной неон» (остаётся открытым), «Кибер-комикс»/«Премиум-золото» (надетые или купленные) → «Коллекция», бывший основной `mix` → новый основной.
- Короткий экран (или баннер «Пригласи друзей» на маленьком телефоне): `fitGrid` в `game.js` включает компактный офис (`.tight`: ниже потребности, «Дальше», подсказка), а если и так тесно — прячет баннер (`.tight2`).

## Доп. места в офисе (0.3)

Сверх 4×N помещения: +1 место за 1, 3 и 10 засчитанных друзей (до +3), +1 и ещё +1 за ⭐ 50 / ⭐ 100 (пока кнопка «скоро»), +1 за 7 дней подряд в календаре — всего до +6, во всех бизнесах и после переезда (`state.slots`, цифры — `SLOT_*` в `balance.js`). Закрытые места видны в сетке с замком, тап — окно «Больше мест». Симуляция: `node tools/simulate.js 40 --extra=6` — темп не меняется (разумный игрок сразу объединяет и не упирается в место; места помогают с пачками и приёмной).

## Сотрудники: рисованные и картинки

Пока картинок нет, во всех комплектах сотрудники рисуются кодом (`app/avatars.js`, SVG «чиби»): форма и предмет по профессии, чем выше уровень — тем солиднее (у 8-го — корона и золото). Внешность одна и та же для пары «бизнес + уровень». Вернуть эмодзи — ⚙️ → «Сотрудники: смайлики».

Как подключить нарисованные картинки (например, из нейросети):

1. Положи файл в папку комплекта `app/img/staff/<main|neon|collection>/` с именем `<бизнес>-<уровень>.webp`: бизнесы — `coffee`, `it`, `barber`, `burger`, `auto`, `fitness`, `gamedev`, `delivery`; уровни 1–8. Пример: `app/img/staff/main/coffee-3.webp`.
2. Картинка — во весь рост, прозрачный фон, примерно 360×450 (пропорция ~4:5), ноги внизу кадра.
3. Допиши имя в список своего комплекта в `STAFF_IMG` (`app/content.js`): `main: ['coffee-3'],`
4. Подними версию `?v=` у `content.js` в `app/index.html` и сделай push.

Кого нет в списке — по-прежнему рисуется кодом, так что картинки можно добавлять по одной.
